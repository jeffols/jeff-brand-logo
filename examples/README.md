# Examples

Worked applications of the brand system. Each shows the marks in a real
context, so a decision in `docs/` can be checked against something concrete
rather than argued in the abstract.

| Directory | Shows |
|---|---|
| `homepage/` | Header lockup, hero treatment, footer mark |
| `linkedin/` | Banner-safe composition, article card |
| `github/` | Profile README header, repo social preview |
| `article-covers/` | The repeatable cover system for Substack posts |

Empty for now. Populate from the real surfaces as they are built, and never
redraw the mark here — import or copy a generated asset.
