# Lockups

Generated by `scripts/generate_lockups.py`. Do not edit by hand.

The wordmark is IBM Plex Sans SemiBold **converted to outlines**, so these are artwork, not font software. They render anywhere with no webfont and no font installed.

Two constructions only (decision 0007):

- `lockup-horizontal-*` — mark beside **Jeff Olsen**
- `lockup-stacked-*` — mark above **jeffols**

Never set the mark horizontally beside lowercase `jeffols`: the mark is a lowercase j and the word starts with one, so it reads as "j jeffols". The capital J in the full name breaks that echo.

`-mono` inherits `currentColor`. `-transparent` has no plate.
